# 決算書複核與財務分析工具 (Financial Report Reconciliation Tool)

本專案為一套專為財務流程設計的現代化複核與分析平台。透過前後端分離架構，結合了智慧核對演算法與靈活的財務計算模組，主要用於自動比對決算書數據差異、計算各項財務及營運比率，並產出清晰直觀的視覺化報表。本工具特別能減輕稽核與財務人員人工核對數字的工作量，提高結算資料的可靠性與準確度。

## 💡 主要功能與特色

### 1. 決算概要數字比對 (Smart Compare)
- **自動化比對**：匯入相關決算報表與預算檔案，系統將自動提取項目並執行數字驗證比對。
- **智慧預警系統**：透過建立稽核規則（支援匯入 JSON 格式的知識庫），可自動識別異常、高風險或差異達 20% 以上的欄位項目，並於畫面上標示 🚩 及 ⚠️ 以利人員進行必要的說明與調查。
- **多元檔案支援**：利用 Python 後端解析引擎支援跨格式資料的比對與萃取。

### 2. 財務比率與營運分析 (Financial Ratio Tool)
- **多年度 XML 自動解析**：支援一次匯入多個年度的「資產負債表」與「損益表」，系統自動判讀並歸戶檔案。
- **指標綜合計算**：支援各種基礎及進階財務與獲利比率的計算（流動比率、負債占資產比率、EPS、ROA、ROE，以及投資報酬分析等）。
- **進階資訊自動提取**：能夠從特定的附表（如 `主要產銷(營運)量值比較表`、`員工人數彙計表`、`現金流量表`）中，**自動抓取預設值**帶入「年平均存款量」、「員工總人數」、「營業活動淨現金流量」等欄位，若未能抓取到數值亦可隨時切換為手動輸入模式。

### 3. 一站式檔案管理中心
- 所有的檔案上傳皆透過共用的檔案管理介面操作，自動偵測檔案類型（Balance Sheet、Income Statement、JSON 規則集等），大幅優化使用者操作體驗。

## 🛠️ 專案技術架構

- **前端 (Frontend)**：`React.js` (Port: 3000)
- **後端 (Backend)**：`Python` + `FastAPI` + `Uvicorn` (Port: 8000)
- **啟動與任務調度**：整合式 Windows 批次腳本 (`start_app.bat`)

## 💻 系統環境需求 (Prerequisites)

在此電腦環境執行此應用程式之前，請確認已安裝下列軟體：
1. **[Python 3.8+](https://www.python.org/downloads/)** （建議勾選 Add to PATH）
2. **[Node.js (LTS version)](https://nodejs.org/en/)** （將自動包含 npm 套件管理員）
3. 支援最新版網頁標準之瀏覽器 (Chrome, Edge, Firefox, Safari 等)

## 🚀 🚀 安裝與啟動步驟

本專案提供了一鍵自動化執行的 Windows 批次檔，您**無須**手動輸入繁瑣的指令。

1. **取得程式碼**：將本專案下載或 `git clone` 至您的本機資料夾中。
2. **一鍵啟動**：進入專案資料夾，雙擊執行檔 **`start_app.bat`**。
3. **系統自動初始化**：
   - 指令碼將自動建立 Python 獨立虛擬環境 (`venv`) 避免干擾您本機的其他設定。
   - 系統依據記錄的雜湊值 (hash) 自動判定並安裝 `requirements.txt` 內之 Python 後端依賴。
   - 系統將自動執行 `npm install` 安裝前端必要套件。
   - **完成後，系統將同時啟動前端與後端伺服器 (將彈出兩個命令提示字元視窗，請勿關閉)。**
4. **開啟頁面**：啟動就緒後，您的預設瀏覽器會自動開啟網址 [http://localhost:3000](http://localhost:3000) 進入系統介面。

*(註：若不想使用自動腳本，您亦可選擇開啟兩個終端機，分別進到 `python_backend` 資料夾啟動 FastAPI，以及在根目錄執行 `npm start` 啟動 React。)*

## 📖 使用者操作說明

進入系統網頁後，您可以按照以下步驟使用系統：

1. **檔案匯入**：
   - 點擊畫面上的 **「檔案總管 (File Manager)」** 面板。
   - 上傳您的 XML 財務報表 (資產負債表及損益表)、相關附表 XML，或 JSON 格式的稽核檢核規則。
2. **功能選擇**：
   - 使用畫面上方或側邊導覽列切換「決算核對比對」或「財務比率分析」等不同頁籤。
3. **執行分析與檢視**：
   - 於**「財務比率分析」** 中選取分析年度，系統會自動帶入並載入對應之比率。點擊展開區塊便能檢視各項分析結果。
   - 於**「決算摘要比對」** 中，介面將透過紅旗 (🚩) 等明確的視覺指示，提示差異大於容忍範圍的項目。
4. **結束系統**：
   - 使用完畢後，直接關閉瀏覽器，並將啟動時所開啟的那兩個黑色命令提示字元視窗（Node.js 背景與 Python 伺服器）關閉即可終止服務。
